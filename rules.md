# CYBERMENTOR DEVELOPMENT RULES

These rules are mandatory.

## Rule 1
Never invent information.

## Rule 2
Never invent URLs.

## Rule 3
Never fabricate YouTube video IDs.

## Rule 4
Never claim an unverified resource is verified.

## Rule 5
Never expose API keys.

## Rule 6
Never put private OpenRouter credentials in frontend code.

## Rule 7
OpenRouter is the current AI provider.

## Rule 8
AI primarily generates quizzes.

## Rule 9
Learning resources are curated data.

## Rule 10
One topic should be able to have its own learning resources.

## Rule 11
Do not replace real database content with mock content.

## Rule 12
Do not silently catch and hide errors.

## Rule 13
Do not make unnecessary architectural changes.

## Rule 14
Do not add unnecessary dependencies.

## Rule 15
Do not build custom CTF/sandbox infrastructure.

## Rule 16
External practical-room links are allowed.

## Rule 17
Do not create unauthorized offensive-security functionality.

## Rule 18
Run tests after meaningful code changes.

## Rule 19
Do not claim tests pass unless they were actually run.

## Rule 20
Do not claim a feature works unless it was verified.

## Rule 21
Keep documentation synchronized with implementation.

## Rule 22
If requirements conflict, prioritize explicit user requirements over assumptions.

## Rule 23
If an implementation decision is unclear, inspect the repository before deciding.

## Rule 24
Prefer the smallest correct implementation.

## Rule 25
Never delete working functionality without a clear reason.
