# UI/UX DESIGN

CyberMentor should feel like a modern cybersecurity learning platform.

## Design Principles
* Clean
* Professional
* Fast
* Responsive
* Easy to navigate
* Cybersecurity-oriented
* Low visual clutter
* Accessible
* Consistent

## Dashboard
Dashboard should expose:
* Learning progress
* Current course
* Recommended next topic
* Career role
* Recent learning
* Quiz performance
* Quick access to courses

## Course Page
Course page should show:
Career Role → Modules → Topics

Each topic should clearly display available resources.

## Topic Page
A topic page may contain:
1. Topic title
2. Topic description
3. Learning objectives
4. YouTube video
5. Books
6. Notes
7. Handbooks
8. Documentation
9. Practical room
10. Quiz
11. Progress

## Video Player
YouTube learning videos should use an approximately 16:9 presentation.
Do not download or illegally redistribute copyrighted videos.
Use legitimate YouTube embedding/linking.

## Notes
Notes should be easy to read and edit.
A focused note editor can use a portrait-oriented layout if that matches the existing design.

## PDF
Where legally available, PDFs/books/handbooks can be opened using appropriate browser/resource viewers.
Do not redistribute copyrighted material without permission.

## Quiz
Quiz interface should show:
* Question
* Options
* Submit
* Result
* Explanation
* Score
* Difficulty
* Topic

## Responsive Design
Support:
* Desktop
* Laptop
* Tablet
* Mobile

## Accessibility
Use:
* Clear contrast
* Keyboard navigation
* Semantic elements
* Labels
* Accessible buttons
* Readable typography
